创建时间：2026-10-26
最后更新：2026-10-26
状态：当前 R5 / R5a / R6 定向组合验证通过；非完整阶段/发布验收。详情见文末组合验证补记。

## 目的与范围

用户切换 Bot、关闭后打开资源工作区或重启应用时，目录阅读现场可恢复，网页实际能保留多少有明确边界。接续 R5-01/02 当前分支；不提交、发布或重启日常实例，不操作任务或原文件。

契约为 ADR109 §28 与 ADR46/47。新增目录状态 kernel 与恢复 hook，WorkbenchContext 仅接线现有设置存储；FilesView 的树初读复用原受限 readDir，navigator 复用 metadataOnly。BrowserPage 从大视图拆出负责 guest 生命周期，BrowserSession 保留兼容字段，局部说明与真实崩溃反馈。不新增 IPC、宿主路径、工具、权限根、System Context 或写入恢复。

## 状态与交互

目录：请求来源→宿主核对→有界加载展开分支→一次恢复坐标；失效时保留原目标并提供重试、当前项目、知识库的显式导航。根变化不采用旧树坐标；子目录删除只裁剪事实不存在的分支。过滤不搜索未加载正文。选中只恢复高亮，不打开文件。复用现有筛选、SVG、局部反馈和 Frost 样式，无新弹层或动画。

网页：原 guest 保留挂载时继续沿原登记与前台控制；重新创建已访问标签时显示 URL 恢复标识，说明表单、页内位置与历史栈未恢复。加载/失败仍取真实事件；崩溃不自动重跑。提示不抢焦点、不自动展开，不修改 Composer。

## 实施与审阅记录

- `directorySessionState` 收口旧设置兼容、最多12根/64展开分支/16层/256字符筛选和坐标规范化；恢复只读新父目录确认的直接子项。失败、来源变化、已删除分支和迟到各有明确路径；被截断的树不能被当成完整恢复来覆盖原记录。
- WorkbenchContext 沿原防抖 updateSettings 保存目录元数据；ScopedResourceNavigator 按 workspaceId 读取，并在 metadataOnly 失败时保留原请求；目录跳转意图消费一次，避免重新挂载重放旧目标。FilesView 只接线 kernel 与读位 hook，恢复不触发 openFile/create/watch。确认的选择补齐已有 data-selected/aria-selected 表达。
- 目录读位在分支加载后只落一次；展开/筛选/选择与坐标防抖保存，卸载收尾交回原 Bot。用户在树上开始操作、滚动或更改筛选即中断未完成的恢复；后台读取不把选择或坐标拉回。传输失败/拒绝保留已接受目录及局部原因，刷新可重核；不把缺权限解释为空树。
- BrowserPage 从 BrowserView 拆出负责现有 guest 的挂载、目标登记、事件与清理；URL/title 回写不改初始 src，原 partition/会话与标签目标不变。按 URL 重建只在当前网页底部提供默认折叠的恢复级别说明，采用共享 MotionDetails/SVG；不新设模态、自动展开或焦点迁移。
- 真实 render-process-gone 事件清除可用句柄投影并注销目标；后续 stop-loading 不重新登记已崩溃 guest，直到新 dom-ready。失败由用户显式重试，导航 Promise 的迟到/中断不会冒充本次成功或重跑任务。事件结构已对照当前安装的 Electron 类型定义（RenderProcessGoneEvent.details），不是仅凭页面文字判断。
- 编写前端 kernel、读位 hook、guest 生命周期用例，及宿主设置往返/逐次 Bot 范围重核用例；宿主实现无需新通道或新模块。包含去除非法路径、Bot/根隔离、上限、故障/迟到、用户读位优先、活 guest 保留和崩溃不自动导航等反例。用例仅编写，未执行。
