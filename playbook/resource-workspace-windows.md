## 01 契约

- 仅信任宿主登记的主窗口对象，先真实 resolver 再分配身份；准备中也计数，窗口上限有界。resolver 异步期间关闭/dispose/身份改变使旧准备失效。
- owner 绑定原 Bot 主会话及可选完整任务对，不随主窗口切 Bot 改变。窗口真实 sender 只能绑定一个租约；别人窗口的 ID、旧 generation 或任意新 sender 不能读取/激活。
- ready 仅代表呈现接线，不能证明读取成功。Registry 不持有 grant，也不读写原文件、调用模型、恢复任务、复制成果或产生 Evidence。
- 导航只保存模式、行号/读位以及有界目录提示；不接受正文、URL 网页实例、图片字节、任意对象、writer、许可字段。每次实际读取仍由原服务重核；Registry 只提供被冻结的来源引用副本。
- 返回来源只提供捕获的原 sender/上下文，失效则提示，不自动换 Bot/窗口。destroy/dispose 只释放自身状态/监听，不取消工作。

## 01 实现收口

- Protocol 增加 `resource-window`：仅文档/比较/目录，只读模式、完整历史提交、任务对、R5 observation、R7 交付引用对与有界导航；未知 owner/window/permission/draft/body/browser 字段拒绝。非法版本、任务或比较端点不降级；没有自动改用工作树。目录最多 64 个展开提示，超限明确失败，不默默丢状态。
- 独立 `resource-view-registry` Module：先真实主 sender 与宿主 resolver，再宿主分配 viewId/windowId/generation。真实子 sender 登记后方可获取自己的 descriptor，ready 才能取读绑定；错 sender、旧 generation 和旧身份复用拒绝。只允许 resolver 规范化路径，不能替换模式、提交、比较基准或来源。
- 并发与中断：pending 同样计入限额；来源销毁、显式 invalidateSource 或 dispose 用 AbortSignal/取消竞争退役准备请求，立即释放名额，迟到结果不分配身份。主窗口 owner 改变只中止未接通视图；已接通视图保持原 Bot/task 与独立读位。尚未 attach 的来源销毁直接清理；已接通后的原来源失效只阻止返回，不取消工作。
- Registry 输出是独立冻结副本；原 sender 只交给宿主返回 Adapter，不通过 Renderer 自报 ID 选目标。原生关闭只清理各自监听/租约；Module 没有 fs/模型/任务/窗口创建、许可或持久化端口。
- 已编写 Protocol 的边界/身份/版本/预算用例和宿主的来源、pending 限额、取消/销毁、错 sender、旧 generation、身份复用、返回来源及清理用例，加入资源组合测试入口。只完成内容/diff 自审；未构建/运行测试/截图。

02 接线必须提供真正受控的主窗口角色、scoped metadata resolver 与子窗口角色，并在每次文件/目录/Git 读取时注入 Registry 中的 owner/reference。不能把 `readBinding` 当成 grant，不能直接把 main window 的完整 preload/API 授给新窗口。01 未新增 IPC 注册、BrowserWindow 或产品入口，当前用户界面仍是已有右侧工作区。


## 02 原生接线收口（2026-10-26，源码完成，未验证）

- 用户在现有右侧文档、目录或比较上明确点击“另开只读窗口”，才创建独立原生窗口；原视图、Bot 草稿与任务保留。旧 preload 未提供此能力时入口隐藏。打开失败只在当前控件提示，可重试。
- 独立 `resource` role 与专用 `peerResource` preload；不挂载 MainApp。仅 bootstrap/ready、绑定内容/目录/Diff 读取、导航元数据、返回及关闭。七项公开外观和界面语言单独提供，接收公开主题变更；无完整设置、模型/任务、写文件、通用 fs 或 browser guest 接口。IPC 继续通过目录、顶层 frame 与 app-origin 核对，主窗口也不能调用 child read。
- 应用 Reader 复用同一个 Bot/task resolver、fileAccess scoped 服务。Registry 的宿主回调私下保留实际根与目标，不把 root/grant 交给 renderer。每次读取重新核 owner、任务及物理来源，目录只读绑定目录的后代；失败不换来源。成功 Directory/Git 回执补充 resolvedPath 并核对，子目录不能被 Git 仓库根替换。Git pathspec 为 literal，未跟踪文件单列，不宣称空 Diff 就是全部无改动。
- 文档复用 Markdown/Source/Raster，比较复用有预算的 Diff Adapter；本地 HTML/SVG 仍只读源码，远程图片不自动请求。本轮原生文档中的其他本地文件引用暂作普通文本，不伪装成可读链接；原会话仍提供既有导航。当前文件与 R7 交付时的依据分开，不制造历史快照。
- 新窗口固定 view/window/generation 与打开时来源，其他 sender 或旧 generation 被拒绝；ready 只表示呈现接线。原生载入失败、30 秒超时、崩溃、关闭或 dispose 只清理自己的窗口与租约；迟到读取不能落回已关闭视图。
- 已接显式返回捕获的原主窗口/Bot。文档原标签仍存在时激活原标签并保留原阅读；原标签已关闭则仅返回会话，不另造比较或覆盖其他标签。目录/比较返回仍经原受控导航，默认恢复右侧而非最大化。原窗口/owner/来源已失效给局部提示，不寻找另一主窗口。
- 文档开启时采集实际读位，副本各自滚动；失败保旧，版本变更仅由显式“加载当前版本”采用。目录树展开/选择、比较文件选择、跨窗口返回的精确锚点与重启恢复仍属于 03，尚未完成，不能把本包记为完整 R5w1。

## 03 连续性收口（2026-10-27，源码完成，未验证）

先补 ADR109 §35，再落地新增的阅读元数据、存储边界与双向导航确认。此节更新 01/02 时的后续工作状态，不追溯地把早期源码称为已经运行通过。

- 修正 02 的真实接线缺口：Registry 的宿主回调原来收到的是规范化请求，缺少实际 root/target，导致工厂二次核对失败；现在传真实 resolver 回执，renderer descriptor 仍不包含这些私有根。补专门反例，避免今后只测请求形状而漏掉工厂接线。
- 目录窗口复用 FilesView 的树、筛选、选择、64 个展开提示和一次性恢复；通过只读列举/打开文件/采集读位端口接入专用桥，不挂载主窗口 Workbench。恢复选择只高亮，不自动打开文件。选择不可达有局部说明；用户操作可打断恢复，错误保旧。目录内文件预览的临时读位仅在本窗口内有界保留，不承诺恢复历史正文。
- 比较窗口有明确文件选择及独立坐标。结构不能可靠索引或超过展示预算时保留原始受限 Diff，不伪造文件索引；原选择消失时保留选择并说明，用户可明确选择“全部差异”。源比较锚点相对于具体文件的 Diff 内容，不依赖外壳标题高度。主窗口比较标签也保存经规范化的选择/坐标，后台重绘不重复定位。
- 文档按正文/源码模式、比较按所选文件保留最多 12 个位置。副本 checkpoint 与打开时的 sourceNavigation 分开；导航单调序号与串行确认阻止迟到覆盖。返回或关闭前即时采集 DOM 与当前领域状态，不只依赖最后一次防抖回调。
- 返回增加真实原 sender 的 request/ack、3 秒失效与取消清理。已存在的原标签/目录使用原视图后续独立读位；原文档标签已关闭只回会话并说明。临时“查看更改”不具有不可变标签身份，因此返回时以捕获的完整比较基准创建/激活一个比较标签，不覆盖已经改变的比较表单。比较重建只使用 sourceNavigation，不拿副本后来位置覆盖原现场。
- 原生关闭有 500ms 的 checkpoint 确认上限，失败/强退保留上次已保存位置；关闭自身与窗口载入/崩溃/dispose 的清理不停止或恢复任务。保存失败可继续阅读、重试保存或关闭；未用 timer 伪造保存成功。
- 在既有 SettingsStore 中新增版本化 resourceWindowReadingHistory，最多 24 条、每 Bot 8 条、每条 16KiB、合计 256KiB。只存来源、引用与导航元数据，不存正文/差异/图片/权限/窗口身份或执行态。未知版本、损坏和超额不覆盖原记录。当前文件的版本条件仅由实际读取回执更新。
- 启动器列出当前 Bot 的独立窗口阅读记录；构造、启动及列举均不创建窗口或读取正文。用户明确点击才重新核 owner/task、原来源绑定及现有权限，创建全新 view/window/generation 租约；来源变化、缺失、拒绝访问或记录不可用分别提示，保留记录。移除仅删除阅读记录；仍打开的该视图不会在关闭时偷偷把记录重建回来。
- 新窗口继续只有专用最小 API；history/restore/forget/return-ack 是 main-only，checkpoint-ack 是 resource-only。所有新 IPC 仍走 catalog/top-frame/app-origin 守卫。默认页面内右侧展开不变。
