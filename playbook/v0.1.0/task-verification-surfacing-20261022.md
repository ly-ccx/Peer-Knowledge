# 内部核验收进任务详情

创建时间：2026-10-22
最后更新：2026-10-22

用户要求主对话由主 Bot 解释结果，内部核验状态进入对应任务状态和详情，同时保留现有任务、对话及证据，不影响正在运行的任务。工程边界先记入 [架构治理 §十五](../../knowledge/architecture/20-architecture-governance.md)。

代码 [PR187](https://github.com/ly-ccx/Peer-Agent/pull/187)，提交 `097b1cd30d4890acb49710f9a5e3f87de7e40fc5`，源码指纹 `9db0d27ecfb9ba5c02a53392a95b700a5b40713a0ab40e861c36f5bb65c3e4d4`。

核验器停止生成 verdict 对话卡和直接写入父会话。任务报告按需提供同一宿主核验详情；模型工具与界面共用投影，主 Bot 通过原 post_reply 说明结果和范围。verifying/verified 进展只进任务状态，Inbox、完成事件、停滞唤醒和界面刷新保留。读取失败、内容版本变化或核验观察变化不能继续展示旧通过结论。

旧记录通过公开交互索引 v3 和兼容投影收拢，不覆写原 JSONL、任务、Tool Result 或 Evidence；旧核验记录仍可按需读取原始过程。测试模拟 RC25 v2 已有缓存，验证异步重建、分页、模型默认交互上下文、混合批准卡及原文逐字节不变。合法用户/机器人发言中的 passed/failed 保留。

- 224 项定向单元/集成测试通过，无失败、跳过或取消；覆盖核验、生命周期、回复、Inbox、任务详情版本绑定、历史分页和隔离读取。
- 受影响依赖与桌面前端构建通过；Protocol、Runtime、Desktop、TUI 类型检查及架构、IPC、SVG/圆角、i18n 检查通过。
- 真实源码 Electron 的隔离窗口覆盖四种结果、历史核验、旧卡隐藏、读取失败重试、进展在任务内呈现、键盘进入/退出、深色 1280 宽窗及浅色 760 窄窗。14 张截图均逐图自审；实现者自审，不是独立审查。
