## RC-01 性能与规模预算验证

**状态：完成（2026-10-02）**。代码PR93合入80e42b5e；最终两平台CI36912497140与干净源测量通过，详见[实施及全部证据](rc-01-performance.md)。

- **级别**：B。**规模**：M。
- **目标**：版本计划 §9.2 的每一项都有可重复的测量脚本与达标结果；新增机器人壳的 Electron smoke。
- **代码锚点**：`apps/desktop/scripts/task-monitor-electron-smoke.mjs`（smoke 写法）、`lab-*.mjs`（隔离数据目录 `~/.peer-agent-lab`）；`dev:lab`。
- **允许改动**：新建 `apps/desktop/scripts/{bot-shell-electron-smoke.mjs, seed-bot-shell-home.mjs, perf-project-agent.mjs}` 与测试；`apps/desktop/package.json`（新脚本条目）；为达标所做的修复（每个修复单独提交，写明对应指标）。
- **实现要点**：
  - 种子数据：200 个机器人、1 万条代理对话消息、10 万条收件箱事件、1 万条记忆。
  - 测量：列表首屏投影、列表搜索、发送到「已收到」、输入队列消费延迟、记忆检索、冷启动恢复、空闲内存；每项跑 5 次取中位数。
  - smoke：启动 → 列表出现 → 进入机器人 → 发送 → 看到回复（脚本化执行器）→ 打开档案 → 切经典界面 → 切回。
- **退出条件**：全部指标达标或负责人书面接受偏差；smoke 在 macOS 与 Linux 通过。
