## GA 发布 `0.1.0`

- **步骤**：
  1. 版本计划 §12.2 清单全部勾选。
  2. `VERSION` 与所有包版本改为 `0.1.0`；README 正式版标记改为 `0.1.0`，beta 标记行删除或保留为「beta 通道：无」（与 `check-version` 规则一致）。
  3. `release-notes/v0.1.0.md` 定稿；`pnpm build:changelog`、`check:changelog`、`release:readiness-check`。
  4. `PeerAgent/dev/0.1.0` 合入 `main`（merge commit，不 squash）；在 `main` 上打 `v0.1.0` tag 并推送。
  5. 确认 release 工作流产物：mac（签名、公证）、Windows、Linux；npm `latest`。
  6. 更新器：auto预发布用户发现严格更高的正式版后毕业；显式beta保持预览池，可在设置中手选正式。0.0.x正式通道用户收到0.1.0。
  7. 知识库：ADR 80–85 状态补「已实现（0.1.0）」；交付状态 D10「已发布」。
- **退出条件**：正式版发布，发布后 48 小时内无 P0。
