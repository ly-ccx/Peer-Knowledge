# 本地看图能力修复

创建时间：2026-10-10；最后更新：2026-10-10。

级别 A/B；ADR 90 Accepted。用户明确要求修复安装版任务看不到本地截图的断点。

允许改动：Protocol 图片契约；runtime-node 图片 Provider/Tool Definition 与聚焦测试；Runtime SDK 的不可枚举宿主侧带保留接缝；Desktop Provider 装配、权限投影、视觉侧带、检查点脱敏与工具规则；对应安装候选与端到端回归测试。代码分支 `codex/local-image-vision` 延续当前独立 Agent / 回复恢复集成基线，PR 以该基线为依赖；不用旧版本基线覆盖已修复的恢复行为。

不许改动：日常用户数据、主工作区已有按钮样式修改、release version、开发预览限制、完成/签收权限真值、无关界面；不新增依赖。

实现与退出条件：落实 ADR 90 验收矩阵，最小实现必须覆盖真实图片投递和许可失败，记录自审及真实模型/安装覆盖范围。先完整记录决策，再实施。提交后同轮推送，以 PR 交付；合并和 RC 发布另按用户指令。

实施状态（2026-10-10）：代码与验证已完成，提交 PR 交付。7,037 项受影响包测试通过、5 项环境跳过；最终 19 项聚焦测试通过；构建、类型与架构检查通过。真实 Electron 和隔离打包模块完成图片读取、投递、审查写入、verify 与恢复重读闭环；原始打包主入口另做启动检查。实施者自审，模型为受控测试适配器；未实连真实模型、未替换日常安装版、未发布 RC。具体证据与限制见 ADR 90 第 10 节。

发布整合记录（2026-10-10）：用户另行授权检查待合入工作并发布RC。代码PR140按139/138堆叠依赖合入开发线，知识PR31已合入main；发布准备PR141合入438d1a6，官方 `0.1.0-rc.11` 已发布。候选/合入两平台CI、135张源码截图自审、正式签名Mac包关键UI及发布后资产/更新/npm/Pages核验通过。[RC11交接与完整证据](rc11-candidate.md)。正式包UI使用隔离合成历史；本地图片链路尚未实连云端模型，原受控模型验收范围与限制保留。
