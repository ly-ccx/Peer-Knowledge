## 问题根因与修复

1. **长文档滚动失效**：选区样式的 `.resource-document { position: relative }` 覆盖原 `.document-page` 的绝对定位，实际页面随长文档膨胀，body 失去有界滚动。移除该覆盖；新增真实 DOM 几何断言验证 body 自己拥有滚动，分模式读位/行定位复跑通过。
2. **编辑按钮没有打开草稿**：pending 时 disabled 导致按钮失焦，异步完成后的“用户已离开”保护误判，丢弃刚打开的草稿。pending 改用 aria-disabled/aria-busy 与即时 busy ref 防双击，真实离开/跨 Bot 保护仍在。实际 Electron 点击、编辑、保存及原生编辑组合通过。
3. **刷新等待遗漏中途通知**：并发调用只等待首轮 Promise，排队读取由 finally 另起，调用方可能仍看到旧索引。改为共享 Promise 内排空已收到的刷新请求，增加并发屏障用例。只读状态，不自动提交、继续或重跑，不改变权限/执行契约。
4. **运行与测试接线缺口**：补 Node 原生 TS 所需扩展名、完整 API 测试替身、node:test 导入、异步清理等待及新 UI 定位器；补共享 SVG 折叠图标满足现有约束。初始 Node 22.14 失败单列为环境问题；统一 Node 25 后最终组合通过。
5. **折叠图标换行**：放大截图发现新 SVG 受全局 block 样式影响，与标题分成两行。为编辑器、草稿库和恢复提示的 summary 设置局部 flex 对齐、去掉重复原生标记，展开时旋转现有 SVG；新增真实几何断言验证图标与标题同一行。重新构建并复跑组合模块与全部 10 组 Electron 联调，替换当前截图。

变更属于局部 UI 与读取控制器修复（C/B）；没有新增 Provider、权限、存储边界或 System Context 入口，不扩展 ADR109 已有契约。
