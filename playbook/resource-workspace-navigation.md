# R6a：辅助导航与比较增强

日期：2026-10-26
状态：本包定向验证通过（2026-10-26），不等于完整阶段/发布验收。
分级：B/C，renderer 的导航/读取投影；不新增 Protocol、IPC、持久字段、读取根或任务动作。

## 目标、布局与事实

- 在宽度足够的资源纸面内，文件或变更导航位于右边，正文/源码/真实 guest 保持原 DOM 位置与领域状态。只有一个文件树实例；独立目录入口仍可使用，窄栏点击导航时采用独立视图。辅助选择为当前 Bot 的临时呈现状态，默认关闭，不跨启动恢复。
- 辅助文件树复用现有 Bot/task resolver、展开/筛选/选择/读位与文件动作，不改变项目或任务 cwd。变更导航只投影当前可见比较的真实索引/选择与已打开比较标签；项目、知识库与任务来源沿已有比较入口，分别保留来源与基准，不把多来源拼成同一 Diff 或自动认领已有本地改动。
- 新加载的比较只有用户显式选择文件时改变当前选项；所选条目消失明确提示，不默默跳到首项。切换/隐藏/不同 owner 清理过期索引，正文和真实 guest 不因辅助栏开合重挂。辅助读取或列表更新不滚动主会话、不抢 Composer/焦点。

## 动态检查与权限边界

现有 watchDirs 没有 Bot/任务引用，不能用来监听 scoped 目录，也不能从辅助栏绕回 legacy watch。此包沿原 readDir/gitDiffRange 受控读取，采用用户显式开启的前台有界检查（默认关、约 5 秒一轮，无重叠）；隐藏、收起、失焦/不可见时停止新轮次，恢复后重新核对。目录只刷新已展开分支，不递归扫盘；每轮仍由原宿主重核范围。失败保留旧树并显示原局部错误。

比较动态检查只对工作树/暂存区一类可变目标开放；完整提交到完整提交不轮询。新结果先作为候选，提示“有新变更”；用户加载后才替换当前 Diff。刷新失败保留已接受正文与索引，迟到/切 owner/卸载不能覆盖新对象。分支首次解析后仍固定完整 SHA，自动检查不能追随移动引用。计时器只发起真实读取，不制造变更、成功、权限或 Evidence。

本包不建立文件 watch/转换/后台执行服务，不写原文件、不触发任务恢复、模型调用、暂存/提交、成果重放或发布。沿 Frost/SVG、原非模态框架和减少动效终态，不增加蒙层/焦点锁。

## 本轮实现与后续验收

- 承载：资源头部提供 SVG 目录/变更导航按钮；资源纸面实测宽度至少 720px 且处于文档/网页域时，在右侧展示一个辅助栏。窄栏转独立入口；收起导航或宽度不足后正文恢复。使用既有中速动效与减少动效开关，不新增蒙层。文件树始终为同一实例，Browser DOM 不移位/重挂。
- 索引：`ComparisonNavigation` 只投影当前可见 `ComparisonRead`，同源不同视图的退出不会撤销另一个视图的索引。点击索引联动正文选项并只定位本地差异滚动容器；后台更新不定位。项目和知识库按钮经原 metadata/resolver 重核，任务/任意范围仍在“更多比较来源”中显式选择；每个比较独立保留，不混合不同来源。
- 检查：`useForegroundRefresh` 和纯调度器提供默认关闭的前台轮询；owner 更换清空选择并退役旧调度器，旧计时器不读取新 owner。目录经原 scoped `readDir` 顺序检查已展开分支，每轮最多 64 个目录，失焦/隐藏后不继续发起下一目录读取；失败保留旧树并暂停后续轮次，仍可手动刷新。此包没有调用无 Bot/task 引用的 legacy watch。
- 比较：纯读取状态机只维护已接受结果、候选与真实失败。自动观察结果不替换正文；显式加载候选或刷新才采用。失败/来源改变/迟到结果不覆盖旧正文，旧候选随失败失效。已选文件消失后提示重新选择，不换成另一文件。固定提交端点与 Bot/task 引用沿原读取模块保留。
- 编写并登记四组模块用例：比较候选/失败/并发/取消/缺来源；前台节流/无重叠/隐藏/退役；宽度与领域边界；索引到正文及打开文件的 Bot/task 来源、所选文件消失不回退。本包未运行这些用例。宿主沿用既有 resolver、范围与 Git 读取用例，未新增执行、权限或 IPC 契约。
- 待定向验收：真实 Electron 的明暗/宽窄切换、同一文件树与 guest 身份、导航开合动效/减少动效、键盘焦点与局部读位、项目/知识库/任务多比较切换、真实文件变动及失败恢复。上轮 338 项/31 图对应变更前组合，不能证明本包通过；当前未形成 R6a 验收截图或通过回执。
