# 87. 用户回合可展开的实时过程

日期：2026-10-05
创建时间：2026-10-05
最后更新：2026-10-05
状态：Accepted
来源：负责人要求修复 RC6 的静态思考提示，并参照提供的 Codex 截图实现进行中扫光、本轮过程与嵌套详情。
级别：A（ProjectAgentActivity 展示协议）；档位保存与几何稳定性为 C。

## 决策

在 ADR 85 的既有 TurnSink → ProjectAgentActivity → 主窗口展示链上增加有界工具展示预览。该决定替代 ADR 85 流式边界中“工具参数、结果、路径不进入摘要”的限制，只对同一用户回合的本机展示生效。不增加 IPC、工具、执行器、权限或持久存储。

- 每个工具保持 toolCallId、名称、准备/执行/完成/失败/停止状态，实际事件时间，以及可选对象摘要、参数预览、返回预览。事件时间沿用 Runner 的时钟 seam。只有 tool-call 可进入执行中；参数生成进度称准备中，不称文件已读取。
- 预览 Module 统一递归过滤凭据/认证/隐藏 reasoning 字段与密钥模式，限制深度、节点数和字符串长度。单参数最多 2,000 字符，单结果最多 4,000 字符，一回合预览累计最多 32,000 字符，条目仍受既有 100 段上限。截断和脱敏必须明确标注。快照只含不可变字符串/标量，调用方修改副本不影响宿主。
- 正文/commentary 仅来自可见 delta 和既有 post_reply 字符串进度。内部 thinking 内容永不展示；没有公开内容时显示“等待模型返回可展示内容”，不编造思考过程。post_reply 的参数和结果不作为普通工具过程展示。
- 主窗口可按需展开实时步骤与每一步详情。默认一行当前动作加耗时，使用低对比文字扫光，无卡片光晕；完成/失败/停止及 reduced-motion 停止移动。展开读取现有快照，不发起能力执行。程序可读状态和键盘展开必须保留。
- tool-result 结束对应步骤；停止/失败会将尚在进行中的步骤转为停止/失败。失败撤销未接受的回复预览，但保留已发生工具的有界过程。disposed 清理所有预览；恢复/重试清理本次尝试，不把旧结果拼进新尝试。旧 turnId、静默唤醒与低优先送达仍按原可见性边界拒绝。
- 正式回合记录仍为历史真源，实时快照仅用于当前回合展示。消息交接后使用既有 agent_turn rounds 查看历史过程，实时与历史统一复用 protocol 内的纯展示预览函数；历史展示也遵守同样的脱敏、条目和累计预算，不改变存储事实。不能把瞬时预览当 Evidence、执行成功或用户验收。

## 档位稳定性

滑块提交保持用户选择直到现有异步保存结束，保存失败回退实际配置并展示已有错误。提交期间阻止重复提交，标签预留最长档位宽度；弹层观察自身与触发器尺寸。不得用 renderer 乐观值充当实际生效模型的真源。

## 验证

协议/投影测试覆盖真实调用前后、参数进度、嵌套拒绝、停止、失败、恢复、乱序、静默、隐藏 reasoning、凭据过滤、截断与总预算。正式 Electron 的受控认知夹具覆盖等待扫光、执行中展开、嵌套参数/结果、键盘/reduced-motion、完成交接、停止/失败及档位延迟保存/失败回退/几何稳定。夹具验证展示链，不宣称验证真实能力执行。
