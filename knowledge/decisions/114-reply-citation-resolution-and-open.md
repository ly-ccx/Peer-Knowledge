# 114. 回复引用的定位与打开

创建时间：2026-10-30
最后更新：2026-11-15（消歧 [ADR 108-bot](108-bot-reply-document-preview.md) 引用）
状态：Accepted。本文件是点击回复引用时的操作规范。
级别：A。它不新增访问根、模型工具或执行链；补齐失败表达和未适配格式的打开动作时，沿既有 file:read 与系统打开。

## 权威关系

允许哪些根、如何阻止越界，以 [ADR 108-bot](108-bot-reply-document-preview.md) 为准。引用类型、右侧工作区、错误语义和格式阶段，以 [ADR 109](109-resource-reference-preview-and-artifact-collaboration.md) 的 §6、§8、§10 为准。

2026-07-05 的 `design/product/workbench-file-preview-rendering.md` 只保留 Markdown 排版和主题 token。它的「待落地」和格式矩阵不再决定引用怎么打开。

模型写出的路径不是文件存在、读取成功、权限或 Evidence。点击是人的只读导航，不产生 Tool Call、Grant，也不扩大模型能读的范围。

## 1. 什么可以点

同一套识别用于正文、行内代码和 Markdown 链接目标。识别只表示「可以请求预览」，不表示文件存在。

算作文件候选，必须满足下面之一：

- 扩展名属于 §4 已登记的文本、代码、图片或文档包。
- 无扩展名的已知文件名：`README`、`LICENSE`、`Dockerfile`、`Makefile`、`.gitignore` 这一类。
- 路径中含 `/` 或 `\`，且最后一段以字母开头的扩展名结尾。

下面保持普通文字，不生成文件入口：

- `http:`、`https:`、`file:` 和其他 scheme。`http` / `https` 走网页入口，不走文件读取。
- 命令：以 `git`、`pnpm`、`npm`、`node`、`cat`、`rg` 等开头的整段。
- Git 引用：`refs/heads/`、`refs/tags/`、`refs/remotes/`、`origin/`，以及以 `/` 结尾的路径。
- 仓库名、版本号和没有文件扩展名的分支，例如 `PeerAgent/dev/0.1.0`、`ly-ccx/Peer-Knowledge`、`release/0.1.0`。
- 紧挨在「分支 / 标签 / branch / tag / git switch / git checkout / git branch」后面的文字，即使它长得像 `docs/review.md`。

`:12`、`:12:4`、`#L12`、`#L12-L20` 是阅读位置，不是路径的一部分。交给宿主的 `path` 不含行号；行号单独传递。行号只对文本和代码生效，图片忽略行号。历史版本只接受完整提交 SHA，不接受分支名或短 SHA。

## 2. 点击之后怎么定位

渲染层不把工作区根和相对路径拼成绝对路径。它把原始路径、行号，以及这条回复里已经保存的文件工具提示交给宿主。

宿主只在这些根里查找，并且先做词法边界、再做 realpath：

1. 当前机器人的项目根。
2. 用户已经登记的工作区，以及当前活动工作区。
3. 按 [ADR 108-bot](108-bot-reply-document-preview.md) 确认过的 Peer-Knowledge 根。显式配置无效就报错，不悄悄换一个。
4. 引用带有任务 `sessionId` 和 `planId` 时，只使用该任务已经记录的交付根。宿主每次重新核对归属。

不递归搜盘，不因为这句话提到了某个仓库就把它登记成新根，不跟随跑出上述根的 `../` 和符号链接。

定位顺序：

1. 这条回复里，成功的 `read_file` / `write_file` / `edit_file` 如果只记录了一个绝对路径，并且该路径等于引用，或以其为后缀，就用这个绝对路径。多个后缀同时命中时不挑一个。这个绝对路径仍然必须落在上面的根内；落在外面是范围不足，不是「文件丢了」。
2. 绝对路径只接受属于上述根的目标。同一路径的系统别名（例如 `/var` 与 `/private/var`）可以核对这一条，不能据此增加新根。
3. 第一段正好等于某一个根的目录名时，余下路径只在那个根里解析。多个根同名则说明歧义，不猜。
4. `Peer-Knowledge` / `peer-knowledge` 前缀只映射已确认的知识库根。
5. 带 `relativeTo`、显式 `./` 或 `../` 的路径保持该基准。失败不改到另一个仓库。
6. 其余裸相对路径先拼到当前机器人根。那里没有这个文件时，再在其他允许根的同一相对位置做精确检查，最多 16 个。一个都没有就是未找到；有一个或多个都先列出来，等人点选，不直接打开另一个仓库的正文。

只有文件名、没有目录的旧引用，例如 `host-lease.mjs`，不按文件名搜索。有唯一的同回复工具绝对路径时用第 1 步；否则提供「查找文件位置」，查找范围仍是上述根。

## 3. 找到之后怎么打开

打开位置是对话旁边的资源区，不是系统编辑器，也不是遮罩弹层。默认模式由已经注册的读取能力决定，不按扩展名假装能读正文。

| 种类 | 扩展名 | 现在怎么打开 | 还没有的能力 |
| --- | --- | --- | --- |
| Markdown | `md` `markdown` `mdown` `mkd` | 正文。可切源码。带行号时打开源码并滚到该行 | 大纲、锚点 |
| JSON | `json` `jsonc` `jsonl` | 能排版就排版，否则原文 | 可折叠树 |
| 代码与纯文本 | 现有代码扩展名，以及 `txt` `log` `csv` `tsv` `yml` `yaml` `toml` `ini` `env` `html` | 源码。带行号时滚到该行 | CSV 表格 |
| 光栅图片 | `png` `jpg` `jpeg` `gif` `webp` `bmp` | 图片预览 | 缩放 |
| SVG、HTML | `svg` `html` `htm` | 源码。不执行脚本，不访问网络，不调用本机文件 | 单独授权的运行预览 |
| 文档包 | `pdf` `docx` `xlsx` `pptx` | 不读正文。说明此格式不能在这里预览，并提供「用系统默认程序打开」和在文件夹中显示 | 内嵌 PDF、Office 转换 |
| 其他二进制或超过文本限额 | 含空字节，或超过现有文本限额 | 不把截断内容当成全文。说明原因，提供在文件夹中显示；文本过大时可以另选外部编辑器 | 把编辑器当成 PDF 的主按钮 |
| 目录 | 宿主确认是目录 | 打开资源区的目录，不用文本读取 | 历史提交里的目录浏览 |

有 Git 改动时，Diff 是用户另外切入的模式。打开引用的默认动作不是 Diff。

## 4. 打不开时怎么说、能做什么

失败留在同一个资源标签里。文案使用现有状态，不把几类失败都说成「文件可能被删了」。

| 状态 | 用户看到 | 接着能做 |
| --- | --- | --- |
| `not_found` | 未能按此引用定位文件，并写出这次使用的机器人项目根 | 重试；在允许根里查找或改选位置 |
| `relative_base_required`、`ambiguous_path` | 有多个位置，请选择 | 列出完整路径，点一个之后宿主重新核对 |
| `scope_denied` | 目标超出当前已确认的来源范围 | 返回。不自动把该目录加为工作区 |
| `permission_denied` | 当前没有读取权限 | 沿既有授权入口，不因这次点击提权 |
| `workspace_unavailable` | 项目或知识库来源当前不可用 | 重新连接来源 |
| `not_file` | 这是目录 | 改从目录入口打开 |
| `binary`、文档包 | 此格式暂不支持正文预览 | 系统默认程序，或在文件夹中显示 |
| `too_large` | 超出预览限额，未当作完整正文 | 外部编辑器或在文件夹中显示 |
| `invalid_ref`、`revision_unavailable` | 历史版本需要完整 SHA，或该提交不可用 | 不拿当前文件冒充当时的内容 |

`not_found` 必须带上尝试过的项目根。现在只显示「请检查来源和完整路径」，没有根，也没有查找入口，这不符合本规范。

## 5. 和当前代码的差距

这些差距按本规范补，不另做一套解析器：

1. 回复里已经有唯一的成功文件工具绝对路径时，点击仍可能把正文里的相对路径原样送去解析。应先换成该绝对路径，再由宿主核对它是否在允许根内。
2. 裸相对路径在机器人根和其他允许根都没有时，失败页没有写出项目根，也没有「查找文件位置」。
3. `pdf`、`docx`、`xlsx`、`pptx` 会先按文本去读，碰到二进制后把「在编辑器中打开」当成主动作。应跳过正文读取，主动作改为系统默认程序。
4. CSV 继续用源码，直到有单独的表格适配器。这不是定位失败。

## 验证

- `PeerAgent/dev/0.1.0`、`origin/main`、`refs/heads/docs/change.md` 和「分支 docs/review.md」不能点成文件。
- `apps/desktop/scripts/example.mjs` 在机器人根内时打开源码；不在任何允许根时，失败页写出项目根并提供查找，不搜整盘。
- 同一回复只有一条成功的 `read_file` 绝对路径，且该路径在允许根内时，短引用打开这一条，不打开同名的另一份。
- 允许根之外的绝对路径，包括工具曾经读过的 `/tmp/...`，得到 `scope_denied`，不把父目录变成新根。
- Markdown 默认正文，代码和 CSV 默认源码，图片默认预览，PDF 不出现正文，主按钮是系统默认程序。
