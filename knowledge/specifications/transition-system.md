## 1. 过渡的责任

UI 体系规定界面由什么构成；动效体系规定变化如何表现；过渡体系规定从一个交互上下文到另一个上下文，**对象、输入、焦点、阅读位置、行动权与恢复责任如何连续**。没有动画的即时切换同样必须满足过渡契约。

一次过渡最少记录：触发者、来源和目标对象 ID、事实依据、需要保留的编辑/读取状态、焦点去向、视口策略、可打断与失败行为。它们是实现说明字段，不是新增 Runtime 协议。业务归约、持久回执和副作用先按既有契约成立；表达层随后消费，动画完成只能收尾表现。

## 2. 十类过渡

| ID / 类别 | 触发与身份 | 必须保留 / 焦点与滚动 | 可用表达 / 中断与降级 |
|---|---|---|---|
| T01 页面/机器人/任务切换 | 用户导航到 workspaceId、conversationId、sessionId；不能靠数组 index 认对象 | 来源草稿及未确认输入仍有责任方；返回恢复该对象的阅读锚点。焦点落目标标题/主操作或保持合法导航焦点，不因后台刷新移动 | 默认即时或一次短 fade；不整页长距离滑动。目标读取失败给原对象与重试；旧响应不能覆盖新目标 |
| T02 模态与嵌套层 | 用户打开、关闭、返回；最上层拥有 Escape | 进入先建立模态边界，再给合理初始焦点；关闭恢复触发者或相邻工作点；底层草稿不卸载重置 | 复用 Overlay/Drawer。退场期间旧层不能继续接收决定；焦点解除遵循实际层边界，尽快交回且不得穿入仍有效的模态。重复关闭只收尾一次；无 animationend 也能完成 |
| T03 锚定菜单/提示 | 绑定真实 trigger，而非缓存屏幕坐标 | 菜单键盘可进出、外点保留新的焦点；tooltip 不夺焦点，Escape 可关闭；锚点移除时关闭或回合理位置 | fade / 小幅 rise；滚动/resize 后重定位。不支持测量时用普通可达面板，不悬空 |
| T04 标签/分段/设置分区 | 相同对象内改变视图或选值 | 选中语义与内容关联先成立；Arrow/Home/End 依语义工作。切换前保住未保存编辑，或明确提供保存/舍弃/取消；不靠 key 重挂载充当数据策略 | 指示器可短移；内容可即时换。重进不重播历史列表；昂贵读取手动激活。快速反向只以最新选择落定 |
| T05 折叠/展开/详情 | 用户显式操作、已解决事项退出 | 展开不抢阅读；折叠立即移除隐藏控件的 Tab 停靠。若焦点在折叠内容内，先交回标题/触发者；保留用户收起意图 | 局部 grid/height 或即时；测量有界。动画 API 不可用/取消/卸载时仍完成静态终态，不能留下永久 inert 占位 |
| T06 待发→已接收→回复 | 同一 inputId / 消息身份，回执与实际事件分别到达 | 乐观气泡标待发送；接收前保留正文/引用/附件的恢复责任。断联未知重试同 ID；流式→持久回复保持同一可读对象 | 不逐 token 入场；历史恢复静态呈现。晚到事件、切换机器人不把 A 的输入落到 B；草稿不被回复重挂载冲掉 |
| T07 决定→执行→核验→交还 | 绑定 approval/card/plan/attempt 等既有身份与版本 | 批准、执行成功、核验、签收和 Git 交回分别取真实投影。旧卡先禁用/失效，新承接状态可见；用户不必追逐移动按钮 | 一次状态变化即可。动画/倒计时不写业务真相；失败保留原因与合法恢复。重连不重复庆祝或重放动作 |
| T08 列表增删/排序/分页 | 稳定 key、游标和原对象 | 用户阅读锚点与选择保持；当前项消失转相邻合理项。删除失败恢复原项；排序先明确是否已保存 | 局部 collapse/必要时受限 FLIP；虚拟列表重测不改变阅读意图。减少动效直接落位；拖动取消回原序 |
| T09 预览/分栏/全屏/窗口 | 用户打开具体 artifact/path/URL，或显式调尺寸 | 返回同一任务和来源位置；预览内部滚动独立；缩放/拖动保留边界、键盘替代和取消；webview 生命周期不因重排被误销毁 | 默认直接打开或短 fade。共享元素仅目标已就绪且坐标有效时启用；不支持即普通打开。pointercancel/失焦/卸载清理，Escape 撤销当前手势 |
| T10 启动/主题/升级/宿主恢复 | bootstrap、真实下载事件、连接/租约/恢复投影 | 内容就绪即可进入；主题/字体/材质变化不重置任务、输入或阅读位置。关闭窗口不等于取消任务；恢复未知执行不能自动重放 | 品牌动画不增加强制就绪等待。升级缩向徽标时徽标先接住请求展示，真实进度随后接管；失败有可返回入口。不支持透明/API、减少动效时完整静态终态 |

T01–T10 是交互类型标识。当前覆盖和计划状态由覆盖表维护；不另设“全产品转场完成”的总开关。

## 3. 统一收尾与竞争处理

1. 先验证目标身份与数据版本，再投影；连续导航使用既有 generation/request ticket、Abort/清理 seam。不能只靠动画排队遮住旧响应。
2. 用户再次操作时，反转或替换当前表达；不等待串行播完一串旧动画。禁用只用于真实不可执行/提交中，不能给所有导航加固定防抖锁。
3. “提交成功”和“面板关闭”分开：提交失败保持现场；提交已生效但关闭异常，不能再次提交。onAnimationEnd、finished、fallback 竞争只完成一次表现收尾。
4. 任何中间态必须能走到静态终态。WAAPI、ResizeObserver 或目标测量不可用时降级；finished 拒绝、animationcancel、组件卸载不留透明文字、遮罩或不可点区域。
5. 关闭/删除/取消由用户动作与宿主事实决定。过渡计时器只允许收尾显示，不能批准、验收、重试工具或创建 Evidence。
6. 分栏切覆盖层是同一对象改变容器；保留选中页、展开状态、编辑草稿与合法焦点。不能在 resize 后自动发送、重载任务或丢弃编辑。

## 4. 动效组合预算

- 沿用 120 / 200 / 320 ms 语义档；普通入场位移沿用 6 / 12 / 24 px。不得在本规范新增弹簧常数。
- 一次上下文交接只保留一个主要空间运动；局部 hover/加载指示可独立，但不让页面、列表、卡片、文字四层同时起舞。
- 导航不为了动画等待网络；loading 根据真实读取立即成立。骨架保持目标几何，不预填业务成功。
- 已就绪内容不为了品牌或“平滑”再强制停留。必要的防闪或播完收尾不能阻止输入、退出和恢复；例外记录实际收益与退出条件。
- 运行时/宿主不支持转场时，操作、名称、静态状态、焦点与回执全部可用。TUI/CLI 使用清楚的文字与选择位置表达同样语义，不复制桌面动画。

## 5. 实现与审阅

优先复用 `Overlay`、`Drawer`、`useMotionPresence`、`useFocusScope`、`SettingsDisclosureContent`、既有 conversation pager/scroll policy 与 Workbench 的稳定 webview 挂载。它们是现有基础，尚有差异；不得从文件注释推导所有调用方已经满足本规范。

只新增有实质 Locality/Leverage 的共享 seam，不为 T01–T10 各套一个空壳组件。每项改造按[当前计划](../../design/product/peer-product-renovation-plan.md)和矩阵编号落卡；触及权限、协议、Evidence、System Context 或存储时升级 A/B 分级。

日常仅内容/diff 审阅；发布时 E13 在最终组合候选验证正向、反向、快速重复、读入失败、失效、卸载、减少动效及 API 降级。静态截图不证明焦点、IME、去重、拖动或未知结果恢复已通过。本轮没有运行产品回归。
