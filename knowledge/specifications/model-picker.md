## 1. 唯一入口

所有选择已配置模型的界面统一使用代码仓 `apps/desktop/renderer/src/ui/model-picker/ModelPicker.tsx`。标准交互沿用输入框现有面板：供应商入口、按组展示的模型列表、已选标记、能力标记和适用参数。不得以普通 Dropdown、CascadingMenu 或另一套模型清单代替。

`ModelPicker` 管触发器、锚定浮层与交互层；已有独立原生浮层宿主使用同一 `ModelSelectionPanel` 的 embedded 形式，不复制模型面板。compact／field 只区分触发器密度，面板是同一实现。只选模型时不显示思考／通道控件，有对应保存回调和真实能力时才出现。

适用：Bot 与经典 Composer、输入建议、角色固定模型、档位主选／fallback、自动模型池、项目模型范围、备用视觉模型、快捷聊天。服务商目录导入／增删配置是模型管理，继续承担远程目录和配置草稿；档位、路由模式和权限等级也不是模型身份。

## 2. Interface 与责任

- 模型身份使用既有配置记录 ID，供应商按稳定 groupId 分组，同名模型不合并。Adapter 接受既有公开菜单投影，不读取凭据或自行调用 Provider。
- 调用方提供分组、当前单选 `selectedModelId` 或多选 `selectedModelIds`、busy／disabled、可访问名称与说明、回调及失败恢复内容。多选只回传本次点击的 ID，集合增删、最小数量和兼容性校验由原 owner 完成。
- 角色／项目可用范围、保存顺序、作用范围、未知模型的显示、继承／默认／不使用等领域选项由 Adapter 提供。组件不自动改全局默认模型，不创建路由策略。
- 单选保留原输入框的显式供应商选择行为，键盘浏览不写配置。多选切供应商只浏览，不增加第一个模型。不可用模型不能提交；旧选择由 owner 保留，不静默找替代项。
- 当前选择、pending、失败和真实保存回执分开；busy 禁止重入但允许阅读列表。组件不新增 IPC、配置库、权限、Evidence 或执行路径。

## 3. 状态、键盘与恢复

复用 useInteractionLayer、定位／过渡 helper、MotionSurface、PeerIcon、Frost token 和模型参数控件。样式跟随共享组件，不依赖聊天页面挂载后才生效；不增加动画常数或设计系统。

默认、hover、focus、selected、disabled、busy、empty、error、stale 按真实值表达。空列表说明无可选模型；错误、重试和待保存反馈由原 owner 注入。已有草稿、Bot／会话身份和读位保留，打开／关闭选择器不发消息、不清输入。

方向键与 Home／End 沿共享导航，只有显式激活提交。IME 优先；Escape 先关供应商列表，再关最上层模型面板。锚定菜单关闭恢复触发者，外点保留新焦点，Tab 可离开。多选 listbox 有 aria-multiselectable，选中与焦点分开，只有一个模型行处在默认 Tab 序列。

长列表内部滚动，长名称可换行或完整查看；field 触发器可换行，compact 沿原输入框空间。视口改变只重定位；减少动效／透明、强制颜色和 API 缺失沿既有静态降级。原生浮层尺寸和正式提交端口仍由原宿主管理。
