## 1. 目标、事实和非目标

用户无 GPT 订阅也能配置 OpenAI、Google 或 Seedream 等图片服务；聊天模型负责理解需求，图片服务独立执行。统一体验是“设置配服务 → 对话调用 → 工作台查看和使用图片”。Skill 是可选指导，不是凭证配置或执行载体。

已验证事实：2026-09-15，以 Peer credential helper 中的 ChatGPT 订阅认证调用 `https://chatgpt.com/backend-api/codex/images/generations`，模型 `gpt-image-2`，得到 HTTP 200。返回 PNG 为 1254×1254、839535 bytes；SHA-256 为 `59ba95f7670b55f3713b4c41f0c08b7cc4ec04411f71e7779c4f3991ab5dad41`。提示词为白底蓝圆，尺寸/质量/背景均为 auto。格式、尺寸、大小与摘要已复核；没有视觉验收画面内容。

证据定位：本会话验证计划 `46dfe7ec-e73a-4cf1-b9a8-8a9772aee191`；请求记录 `local-shell-artifact://shell_8eb75608-f108-4c9b-8933-3c067236a2bf/stdout`；复核记录 `local-shell-artifact://shell_6726c8bb-452a-4413-8463-6a9ca32408a0/stdout`。这些是现场证据，不是克隆仓库后可用的依赖，也不包含应提交的凭证。

该事实只证明当前账号的一次文生图成功，不证明其他账号、编辑、额度、长期可用性或正式产品接入。OpenAI API Key、Google、Seedream 尚未在 Peer 实测；接入前按阶段门禁验证。订阅路径首发标记“实验性”。Seedance 属于视频生成，不纳入本规格；字节图片目标为 Seedream。

首版仅文生图、单张图片。暂不做独立图库/生图工作台、批量任务、视频、图片编辑、参考图上传、透明背景高级控制及通用 hosted tool 平台。允许未来适配器增加能力，但未实现操作不得出现可点击入口。

## 2. 服务配置与选择

### 2.1 服务商页面

复用“设置 → 服务商 → 已连接服务 / 添加服务”。增加用途筛选“全部 / 对话 / 图片生成”和“默认生图服务”。连接卡展示连接别名、认证方式、可配置能力及能力验证状态；同一厂商允许多个连接。只配生图的连接可以不含任何聊天模型，不改变聊天默认值。

展示示例（非已上线目录）：

```text
默认生图服务 [Google · 个人连接 / 图片模型 ▾]
已连接服务
  OpenAI · 工作连接   API Key     对话 / 图片生成   [管理]
  ChatGPT · 个人连接  订阅登录    图片生成（实验性） [管理]
```

“厂商适配器支持”“连接已保存”“认证有效”“当前模型文生图已验证”是不同状态。只显示已实现的厂商入口；对话连接测试通过不能把图片能力标绿。API Key 不保证模型权限、地区可用性或余额。

### 2.2 添加与管理

表单顺序：服务入口 → 使用已有连接/新建连接 → 对应认证 → 图片模型 → 高级设置 → 保存。OpenAI API 与 ChatGPT 订阅是独立入口/认证配置，不能把订阅 token 当作 OpenAI API Key。Google Gemini API 与 Vertex AI 不混为同一认证表单；首轮只接 Gemini API，Vertex AI 待独立认证适配后开放。

已有连接复用 credential reference，不复制秘密。模型选项来自适配器支持信息、已核验目录或显式手动输入；目录不可用要标明来源，不能伪称实时账号目录。任意“OpenAI 兼容地址”不默认拥有图片兼容性。

保存配置只写配置，不出网生成。独立按钮“生成测试图…”展示服务、模型、测试提示词及“可能产生费用/消耗订阅额度”；授权后仍走相同能力执行链，并返回真实图片结果。测试失败不删除已保存配置。

### 2.3 路由与变更

优先级：本次显式选择（含用户自然语言明确指定并消歧后解析）→ 全局默认生图 binding。无可用目标时返回配置引导，不猜测账号或自动轮询其他服务。选择包含 connectionId + modelId；临时切换不修改默认值。聊天模型不是路由条件，但须支持当前工具调用流程。

提交时生成不可变调用快照；之后改默认值、模型或连接名称不影响进行中的请求。禁用/删除被默认引用的 binding 后默认变为不可用并提示重选，不静默改到别家。修改凭证、模型、地址使旧验证标记过期。旧配置迁移不自动开启生图或计费授权。

## 3. 对话入口

自然语言是主入口。输入框现有“＋”保留添加附件并新增“生成图片”；点击后显示可移除意图标签、服务/模型选择和受支持的比例选项。聊天模型选择器仍独立存在。首版参数默认 auto，显式不支持的参数必须在请求前报错，不静默丢弃。

```text
帮我生成极简蓝白网站封面……
[图片生成 ×] [Google · 图片模型 ▾] [比例：自动 ▾]
＋                       聊天模型：Claude    发送 ↑
```

无配置时在对话就地显示“尚未配置图片生成服务 / 配置生图服务”。深链打开服务商图片筛选；返回后保留草稿与本次意图，需用户发送才能生成，不因配置完成自动计费。快捷入口不能绕过工具权限链直接调用 HTTP。

## 4. 执行状态与恢复

状态流：等待授权 → 正在提交 → 服务处理中 → 正在保存 → 完成。另有拒绝、失败、结果未知、停止等待和保存失败；不能用一个泛化 success 表示远端生成与本地交付都成功。

| 情况 | 界面与执行规则 |
|---|---|
| 正常处理中 | 展示实际连接/模型和订阅/API 类型；无真实进度不显示百分比或编造剩余时间 |
| 登录失效 | 重新登录/更换凭证；复用既有刷新流程，不把秘密交给 Renderer |
| 额度不足 | 管理服务或由用户选择别的服务；不自动切换收费来源 |
| 不支持参数 | 提交前列出冲突；保留输入，要求调整 |
| 网络超时、提交结果不明 | 显示“结果未知，重试可能再次消耗额度”；先查询远端任务（若支持），不自动重发生成 |
| 用户停止 | 只有确认远端取消才显示“已取消”；其余为“已停止等待，远端可能继续处理或计费” |
| 图片返回但保存失败 | 保留可恢复的暂存引用与证据，重试保存不重新生图；不可恢复时明确说明，不宣称已交付 |
| 应用重启 | 恢复已持久化记录；有任务查询能力则对账，否则未知；绝不重放生成请求 |

重试、再生成一张和切换服务都是新的消费请求，受明确授权约束。一次用户操作只分配一个本地 requestId；重复点击、重复事件不能重复出网。服务端未提供幂等保证时不得声称 requestId 能消除远端重复计费。

## 5. 图片交付与工作台

结果卡包含预览、显示名、实际 MIME/尺寸、实际服务与模型、“已保存到本次对话”，动作“查看大图 / 保存到项目 / 再生成一张”，生成详情默认折叠。只有持久化成功且结构化 UserArtifact 登记完成才显示完成。

图片作为受治理会话产物持久保存，不依赖临时 URL 或系统临时目录。工具返回 image UserArtifact 和 evidenceRefs；Renderer 不从 assistant 文本、stdout、路径字符串猜测产物。现有 image 投影若文案仍叫“截图”，应改为能覆盖生成图片的中性文案，保持原截图行为兼容。

查看大图复用工作台 DocumentView；保存到项目是独立的授权写入，选择目标、校验路径和同名覆盖。权限拒绝不得影响原会话产物。再次生成创建新调用/产物，不覆盖旧图。详情含用户提示词、实际参数、服务/模型、时间和可用的用量信息；未知费用显示未知，不把订阅标成免费。提示词按会话隐私策略保留，认证信息永不入详情。

## 8. 交叉测试矩阵

测试名为待实现用例标识，不代表已执行。轴来自本规格：服务/认证、连接复用方式、入口、路由、聊天模型、授权/费用、结果和产物操作。用分组笛卡尔积覆盖相关轴，避免用单厂商成功代替多来源契约。

### 8.1 服务 × 连接来源（每格独立用例）

| 服务/认证 | 新建仅生图连接 | 复用已有连接 |
|---|---|---|
| ChatGPT 订阅 | CFG-SUB-NEW | CFG-SUB-REUSE |
| OpenAI API Key | CFG-OAI-NEW | CFG-OAI-REUSE |
| Google Gemini API Key | CFG-GGL-NEW | CFG-GGL-REUSE |
| Seedream 服务 Key | CFG-SEED-NEW | CFG-SEED-REUSE |

每格断言：可保存且零生成请求；绑定正确凭证引用；图片模型不进入聊天默认；秘密不出现在 UI/日志/工具输出；重启配置保留。SUB 不得把 token 发给 API Key 平面。Vertex AI、图片编辑、Seedance 不在矩阵，原因见 §1/§2 的首版范围。

### 8.2 服务 × 入口 × 路由

对上表四个服务逐个运行下列四格，完整测试名为 `RUN-{SUB|OAI|GGL|SEED}-{格名}`，合计 16 个具名用例。

| 入口 | 全局默认 | 本次显式选择 |
|---|---|---|
| 自然语言 | NL-DEFAULT | NL-EXPLICIT |
| 输入框生图标签 | UI-DEFAULT | UI-EXPLICIT |

每格断言：同一授权/工具链，只出网一次，快照中服务模型正确，结果来源可追溯；显式选择不修改默认。另对每服务执行 `TEST-{服务}-ALLOW`、`TEST-{服务}-DENY`，验证测试图走同一链且拒绝零请求。

### 8.3 聊天模型 × 生图服务

| 聊天模型（支持工具调用的测试实例） | 订阅图片 | OpenAI API | Google | Seedream |
|---|---|---|---|---|
| GPT | CHAT-GPT-SUB | CHAT-GPT-OAI | CHAT-GPT-GGL | CHAT-GPT-SEED |
| 非 GPT（如 Claude） | CHAT-OTHER-SUB | CHAT-OTHER-OAI | CHAT-OTHER-GGL | CHAT-OTHER-SEED |

断言路由只使用图片 binding，不从聊天 provider 取图片凭证；工具正确接收图片产物。无工具调用能力的聊天模型运行 `CHAT-NOTOOLS`，明确不可执行，不静默换模型。

### 8.4 消费动作 × 授权

| 动作 | 允许 | 拒绝 |
|---|---|---|
| 初次生成 | AUTH-FIRST-YES | AUTH-FIRST-NO |
| 再生成一张 | AUTH-AGAIN-YES | AUTH-AGAIN-NO |
| 结果未知后重试 | AUTH-UNKNOWN-YES | AUTH-UNKNOWN-NO |
| 换服务生成 | AUTH-SWITCH-YES | AUTH-SWITCH-NO |

每格在订阅与 API 两种费用类型各执行，命名后缀 `-SUB` / `-API`（16 例）。允许仅在策略授权且用户知悉可能消费时发起；拒绝零请求。未知后无静默重试；服务切换后重新绑定授权范围。KEY-ISOLATION 断言自定义地址/跨域重定向不得携带无关服务凭证。

### 8.5 服务 × 结果状态

对四个服务各执行 `STATE-{服务}-{SUCCESS|AUTH|QUOTA|UNSUPPORTED|TIMEOUT|STOP|SAVEFAIL|RESTART}`（32 例）。用可控 mock 确定触发顺序：

- SUCCESS：验证 MIME/解码/大小上限、真实尺寸与哈希，完成卡含持久产物。
- AUTH/QUOTA：区分登录和额度错误，零自动切换。
- UNSUPPORTED：发出请求前拦截，不静默丢参数。
- TIMEOUT：结果未知，禁止自动生成重试；重复终态事件只登记一个结果。
- STOP：模拟远端支持/不支持取消两个子例，分别确认取消或停止等待，不宣称费用撤销。
- SAVEFAIL：已返回图，仅恢复保存；无第二次生成请求。
- RESTART：处理中/已完成两个子例，恢复记录不重放生成，已保存图可打开。

### 8.6 产物动作 × 文件状态

| 动作 | 文件可用 | 文件缺失/不可访问 |
|---|---|---|
| 对话预览/工作台打开 | ART-OPEN-OK | ART-OPEN-MISSING |
| 导出新路径 | ART-EXPORT-OK | ART-EXPORT-MISSING |
| 导出覆盖已有文件 | ART-OVERWRITE-OK | ART-OVERWRITE-MISSING |

每个导出用例再执行授权允许/拒绝子例；覆盖额外验证未确认零覆盖。原会话产物不受导出失败影响。`ART-EVIDENCE` 检查只由结构化 UserArtifact 投影；包装回执不覆盖原元数据，stdout 不变成图片卡。

### 8.7 配置和界面回归

`MIGRATE-LEGACY`：旧配置不丢字段、不自动启用生图；`DEFAULT-DELETE`：默认连接删除后失效而非换服务；`VERIFY-STALE`：凭证/地址/模型变更撤销验证标记；`SNAPSHOT-CHANGE`：进行中切默认不影响请求；`DRAFT-RETURN`：无配置深链往返保留草稿且零消费；`ATTACH-REGRESSION`：附件流程不变；`UI-KEYBOARD` / `UI-NARROW`：键盘和窄屏可操作；`FEATURE-OFF`：能力关闭不影响聊天和旧图片读取。

实际实施时为每个 ID 记录测试文件、命令、结果、证据；未支持厂商只能标 blocked/out-of-scope 并关闭入口，不能写 passed。单元/契约 mock 绿不等于真实服务可用；真实冒烟单独授权、每服务单张且避免重复计费。

## 9. 发布与回滚
